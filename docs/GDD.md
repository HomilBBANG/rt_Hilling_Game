# god — 게임 기획서 (구현 기준)

> 이 문서는 **현재 실제로 구현된 내용**을 기준으로 정리한 기획서입니다. 수치는 `data/*.xlsx`(→ json)의 현재 값입니다.
> 구조/작업 방법은 `docs/HANDOFF.md`, `docs/ARCHITECTURE.md` 참고.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제목 | **god** (구 가칭 "벨라미") |
| 장르 | 2D 도트 생존 + 힐링 시뮬레이션 (낮 탐사 / 밤 돌봄) |
| 엔진 | Godot 4.7 (GL Compatibility), 1280×720 |
| 시점 | 탑다운(탐사), 고정 화면(캠프·요리) |
| 핵심 판타지 | 폐허를 탐사해 재료를 모으고, 밤에 요리를 해 **god**을 돌본다. god의 누적 만족도로 죽은 동료(NPC)가 부활하며 캠프가 성장한다. |

### 1.1 하루 루프
```
[로비] → 아침(캠프) → 탐사 → 밤(요리) → 다음 날 아침 …
```
- 각 페이즈 시작 시 **자동 저장**(세이브 슬롯 1개).
- 아침에 탐사 가방의 물건(총알 제외)은 모두 **창고로 자동 입고**.
- 매일 아침 god의 **선호 음식 1~2개**가 해금 레시피 중에서 새로 선정.

## 3. 아침 — 캠프

### 3.1 구성
- 플레이어가 캠프를 자유 이동(WASD). 이동 모션은 `idle_hand` / `run_hand`.
- **god**: 캠프에 상주(`god_idle` 애니메이션).
- **NPC 시체/부활 NPC**: 미부활 = `npc_a_dead`(왼쪽 90° 회전), 부활 = `npc_a_idle`.
- 모든 위치는 엑셀로 개별 조정: NPC → `npc_unlocks.xlsx`의 x/y, god·플레이어 → `balance.xlsx`의 `camp_*` (화면 비율 0~1).

### 3.2 NPC 부활
- god의 **누적 만족도(trust)** 가 임계값을 넘으면 다음 아침 부활 컷씬 재생.

| 임계 | NPC | 역할 | 해금 내용 | 구현 상태 |
|---|---|---|---|---|
| 100 | 카터 | 고유 | 무기 제작/강화(대장간) | ✅ |
| 250 | 카밀라 | 배치형 | 서빙 보조 | ✅ (요리 시 배치) |
| 450 | 엠마 | 배치형 | 주방 보조 | ⚠ 배치만, 효과 미구현 |
| 700 | 리암 | 고유 | 새 탐사 지역 | ❌ 미구현 |

### 3.3 카터의 대장간 (카터 근처에서 E)
- **무기 강화**: 원거리/근접 각 최대 5레벨. 비용 `20 + 레벨×15` 토큰. 레벨당 공격력 원거리 +10, 근접 +15.
- **무기 제작**: `craft_cost` 토큰으로 신규 무기 제작(아래 5.3 표).
- 무기 교체(장착)는 **캠프에서만** 인벤토리 화면으로 가능.

### 3.4 능력치 화면 (Tab)
토큰으로 플레이어 기본 능력치 업그레이드. 탐사·요리·캠프 공통 적용.

| 능력치 | 기본 | 레벨당 | 최대 레벨 | 비용 |
|---|---|---|---|---|
| 체력 | 100 | +20 | 5 | 15 토큰 |
| 이동속도 | 280 | +20 | 5 | 15 토큰 |

### 3.5 탐험 준비 (탐사 나가기 버튼)
- 좌측 **가져갈 가방** / 우측 **창고**, 64×64 슬롯, **드래그 앤 드롭**으로 이동.
- 가방은 **무게 제한(50)** 적용 — 초과분은 옮겨지지 않음.
- `탐험 시작` → 가방 내용 그대로 탐사 인벤토리로 진입.

## 4. 낮 — 탐사 (폐허)

### 4.1 기본 규칙
| 항목 | 값 |
|---|---|
| 맵 | 3200×2400 통배경(`explor_bg_1`), 나무 장애물 배치, 외곽 벽 |
| 제한 시간 | 150초 (`scavenge_seconds`) |
| 몬스터 | 일반 16마리(종류 순환) + 지역 보스 1 |
| 채집 노드 | 24개 (음식/재료) |
| 탄약 픽업 | 3곳, 각 6발 |
| 귀환 | 출구 구역에서 E/Enter → 정상 귀환 |
| 강제 귀환 | 시간 종료 or 체력 0 → **이번 탐사 채집물 절반 손실** |

- 카메라 줌 2, Y-정렬로 나무 앞/뒤 자연스럽게 겹침(발 기준 정렬).

### 4.2 조작
| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 8방향 이동 |
| 마우스 | 조준 (팔·총이 마우스 방향 회전, 좌측 조준 시 상하 보정) |
| 좌클릭 | 원거리 사격 (탄약 1 소모) |
| 우클릭 | 근접 공격 (조준 방향 ±60° 부채꼴 즉시 타격) |
| E | 채집 / 바닥 아이템 줍기 / 시체 루팅 / 출구 귀환 |
| 1 | 퀵슬롯 회복 아이템 즉시 사용 |
| I | 인벤토리 (게임 일시정지) |

### 4.3 전투
- **사격**: 장착 무기 스프라이트(`pistol.png`/`riffle.png`)와 무기별 총구 위치(`muzzle_x`)에서 총알 발사. 사거리는 `<무기id>_range`(권총 160px). 탄약 없으면 머리 위 빨간 "탄약이 부족합니다"(0.2초 유지 후 페이드).
- **근접**: 칼 사거리 60px(`knife_range`).
- **피격 연출**: 플레이어·몬스터 모두 0.1초 흰색 틴트. 플레이어 피격 후 0.8초 무적.

### 4.4 몬스터 AI
- 평소 **배회**(배회 반경/속도), 감지 범위 안에 들어오거나 피격 시 **추적**(일정 시간 지속).
- 플레이어 코앞(stop_distance)에서 멈추고, **공격 범위 표시(예고)** 후 공격 → 겹침/버벅임 방지.
- **장애물 회피**: 나무·벽에 막히면 벽을 따라 우회해 추적 지속. 배회 중 막히면 목적지 재선정.
- **사망**: 즉시 사라지지 않고 **어둡게 처리된 시체**로 남음 → 다가가 E 2초 → 드롭 테이블에 따라 아이템 드롭.

| id | 이름 | HP | 공격 | 속도 | 감지 | 공격범위 | 쿨다운 | 드롭 (확률, 수량) |
|---|---|---|---|---|---|---|---|---|
| monster_a | 떠돌이 | 50 | 15 | 90 | 160 | 48 | 1.2s | 고철 100%, 1~2 |
| monster_b | 추적자 | 80 | 18 | 78 | 240 | 60 | 1.6s | 고철 100%, 1~3 |
| monster_c | 날쌘이 | 35 | 12 | 110 | 120 | 40 | 0.9s | 고철 70%, 1 |
| ruins_boss | 폐허의 파수꾼 (**보스**, 2.6배 크기) | 300 | 30 | 72 | 340 | 78 | 1.8s | 고철 100%, 6~12 |

- 보스는 이름표/체력바 **비표시**(크기와 능력치로만 구분). 맵 상단 중앙 스폰.
- 스프라이트: `monster_a`는 idle/walk 애니메이션 적용, 나머지는 임시 도형.

### 4.5 인벤토리 / 무게 (I)
- 64×64 슬롯, 아이콘 + 스택 수량 표시. 가방 무게 / 최대 무게 표시.
- 무게 초과로 못 주우면 머리 위 빨간 **"너무 무거워"**.
- **우클릭 메뉴**
  - 사용하기 (소비 아이템만) — 체력 회복, **체력이 가득 차면 사용 불가**
  - 퀵슬롯 등록 (소비 아이템만) — 1번 키에 등록
  - 버리기 — 2개 이상이면 **수량 선택** 후 버림. 플레이어 발밑에 떨어지며 E로 다시 줍기 가능, **다음 탐사까지 유지되지 않음**.

### 4.6 탐사 HUD
- 좌상단: **남은 시간만** 표시.
- 좌하단(바닥 라인 정렬): **체력바**(빨간 면만 감소) → **탄약 아이콘 ×N** → **퀵슬롯(1)**.
- 인벤토리 화면은 항상 HUD보다 위에 표시.

## 6. 밤 — 요리 (god 돌봄)

### 6.1 준비 화면
- **NPC 배치**: 부활한 배치형 NPC를 슬롯(서빙/주방)에 배치.
- **레시피 선택**: 오늘 만들 레시피 다중 선택(해금·재료 보유 여부 표시) → `요리 시작`.

### 6.2 요리 진행 (60초, `night_seconds`)
- 화면 구성: 상단 바 10% / 필드 80% / 하단 바 10%.
- **조리대 근처에서만** 요리 가능. 완성품을 들고 직접 god에게 이동해 서빙.
- **서빙 NPC 배치 시**: NPC가 직접 걸어가 god에게 배달(대기 → 운반 → 복귀).
- 미니게임 2종

| 방식 | 규칙 | 등급 |
|---|---|---|
| 조합 순서형 | 재료를 정해진 순서대로 투입 | 실수 0=A, 1=B, 2+=C |
| 타이머형(튀김) | 목표 시간에 건지기 | 오차 ≤0.4s=A, ≤1.0s=B, 그 외 C |

### 6.3 레시피
| 레시피 | 방식 | 재료 | 해금 |
|---|---|---|---|
| 들풀 무침 | 조합 | 들풀, 통조림 | 기본 |
| 통조림 스튜 | 조합 | 통조림, 들풀, 통조림 | 기본 |
| 들풀 튀김 | 타이머(3초) | 들풀 | 기본 |
| 감자튀김 | 타이머(4초) | 감자 | 감자 획득 |
| 감자 수프 | 조합 | 감자, 통조림 | 감자 획득 |
| 든든한 스튜 | 조합 | 통조림, 들풀, 감자 | 감자 획득 |

### 6.4 보상 / 판정
| 등급 | 만족도 | 토큰 |
|---|---|---|
| A | +25 | +30 |
| B | +16 | +18 |
| C | +8 | +8 |

- god의 **선호 음식**이면 만족도·토큰 **×1.5**.
- 세션 종료 시 만족도 ≥ **60**(`target_satisfaction`) → **성공**, 예정 토큰 지급.
- 실패 시 토큰 없음 + 불만도 +10.
- 만족도는 성공 여부와 관계없이 god의 **누적 만족도**에 더해져 NPC 부활 판정에 사용.

## 7. 성장 / 경제 요약

```
요리(만족도) ──► 누적 만족도 ──► NPC 부활 ──► 대장간·서빙 등 기능 해금
     │
     └──► 토큰 ──► 무기 강화/제작 · 능력치(체력/속도) 업그레이드
탐사 ──► 재료(음식·고철) ──► 창고 ──► 요리 재료
```

## 8. 아트 / 연출 규격
- 기준 타일 32px, Nearest 필터, 확대는 **카메라 줌**으로 통일(탐사 줌 2, 캠프/밤 스프라이트 ×3).
- 플레이어: 탐사 `idle`/`run`, 캠프·요리 `idle_hand`/`run_hand`. GIF는 프레임별 **독립 추출**(잔상 방지).
- 팔(arm)·총(gun)은 별도 스프라이트로 조준 회전, 무기별 총 스프라이트 교체.
- 총알: 지름 5px 소형 탄.

## 9. 데이터 파이프라인 (기획자 조정 방법)
| 엑셀 | 조정 항목 |
|---|---|
| `balance.xlsx` | 탐사/밤 시간, 목표 만족도, 무기 사거리(`<id>_range`), 능력치(`stat_*`), 캠프 위치(`camp_*`), 가방 최대 무게 |
| `monsters.xlsx` | 몬스터 능력치·AI·공격·드롭 테이블·보스 여부·크기 |
| `items.xlsx` | 아이템 무게·스택·소비/회복량·아이콘 |
| `weapons.xlsx` | 무기 공격력·제작비·탄약 사용·스프라이트·총구 위치 |
| `npc_unlocks.xlsx` | NPC 부활 임계값·해금 기능·캠프 위치 |

**작업 방법**: 엑셀 수정 → 저장 후 **엑셀 닫기** → 게임 실행 (실행 시 자동 변환). 레시피·지역은 `resources/*.tres`(Godot 리소스).
